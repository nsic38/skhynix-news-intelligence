# SK hynix News Intelligence v4.3

## 핵심 변경

### MAIN POINT
제목 아래 한 줄은 기사 메타 설명이 아니라,
본문에서 가장 높은 의미 점수를 받은 '변화/영향' 문장을 사용합니다.

예:
`반응형 AI에서 에이전틱 AI로 AI 워크로드가 진화하면서 메모리의 역할도 달라짐`

### WHY IT MATTERS
카테고리 고정 문구를 사용하지 않습니다.
각 기사의 MAIN POINT + 보조 KEY POINT + 기술 주제를 결합해
그 기사에서 확인되는 변화가 왜 중요한지 생성합니다.

### WHAT YOU GET
현재 기본 직무는 `양산기술`입니다.
해당 기사에서 검출된:
- 양산 전환
- 수율·품질
- 공정 최적화
- 생산성·원가
- 장비·현장
- HBM·패키징
- 메모리 기술
- 데이터 기반 문제해결

중 어떤 축과 연결되는지 기사마다 다르게 분석합니다.

### 양산기술 관련성 별점
일반 기사 중요도가 아닙니다.
현재 선택 직무인 `양산기술`과의 관련성 ★1~5입니다.

`job_profiles.py`로 별도 분리되어 있어,
향후 공정기술/설비기술/품질/소자 등 프로필을 추가할 수 있습니다.

## 데이터 흐름

최초 실행:
최신 고유 기사 10개 → 본문 분석 → DB

이후:
RSS + 전체보기 목록 확인
→ 기존 DB와 비교
→ 새 기사만 본문 분석
→ DB에 누적

## 실행

```powershell
py -m pip install -r requirements.txt
py run.py
```
